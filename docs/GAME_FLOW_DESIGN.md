# ゲーム進行フロー設計書

## ゲーム全体の流れ

### 1. ゲーム開始
```
スタート画面
    ↓
新規ゲーム / コンティニュー選択
    ↓
難易度選択（初回のみ）
    ↓
オープニングムービー（スキップ可能）
```

### 2. 第1章：チュートリアル段階
```
地球脱出シーケンス（ストーリー）
    ↓
3D発射シーケンス（インタラクティブ）
    ↓
宇宙空間チュートリアル
    ├→ 移動操作
    ├→ 射撃・武器切り替え
    ├→ エネルギー管理
    └→ レーダー・マップ確認
    ↓
最初の戦闘（ヴォイド・スカウト×3）
    ↓
ルナとの会話イベント
    ↓
最初のステーション到着
```

### 3. メインゲームループ

```
ステーション/惑星
    ├→ ストーリーイベント
    ├→ ミッション受注
    ├→ 装備購入・強化
    ├→ 情報収集
    └→ セーブ
    ↓
宇宙空間探索
    ├→ メインミッション
    ├→ サイドミッション
    ├→ ランダムイベント
    ├→ 資源収集
    └→ 新エリア発見
    ↓
戦闘
    ├→ 通常戦闘
    ├→ ボス戦
    └→ レイドバトル
    ↓
報酬獲得
    ├→ 経験値
    ├→ クレジット
    ├→ アイテム
    └→ ストーリー進行
```

## ストーリー進行とゲームシステムの連動

### ロック＆アンロックシステム

#### 初期状態
- 利用可能：地球軌道ステーション、月面基地
- 武器：パルスレーザーのみ
- 機能：基本操作のみ

#### 第1章クリア後
- 解放：火星エリア
- 新武器：ラピッドファイア、スキャッターショット
- 新機能：ブーストゲージ強化

#### 第2章進行中
- 解放：木星ステーション、小惑星帯
- 新武器：プラズマキャノン、ホーミングミサイル
- 新機能：シールドシステム、武器カスタマイズ

#### 第3章以降
- 解放：土星リング、外惑星
- 全武器解放
- 新機能：ワープドライブ、特殊アビリティ

### ミッションタイプとストーリー

#### ストーリーミッション
- **必須**：メインストーリー進行に必要
- **演出**：開始時と終了時にイベントシーン
- **報酬**：ストーリー進行、新エリア解放、重要アイテム

例：
```
Mission: "火星の救難信号"
前提：第1章クリア
内容：火星コロニーからのSOS調査
演出：到着時に破壊されたコロニーの映像
結果：生存者発見、火星基地解放
```

#### サブミッション
- **任意**：追加報酬とキャラクター深堀り
- **種類**：
  - 護衛ミッション
  - 殲滅ミッション
  - 調査ミッション
  - 配達ミッション
  - タイムアタック

#### 緊急ミッション
- **ランダム発生**：探索中に突発的に発生
- **制限時間**：あり
- **高報酬**：レアアイテム確率上昇

## プレイヤーの成長曲線

### レベルシステム
- **パイロットレベル**：全体的な能力向上
- **武器熟練度**：各武器の使用で向上
- **スキルポイント**：レベルアップで獲得

### 難易度カーブ
```
第1章：学習期間
- 敵の攻撃は緩慢
- ダメージ低め
- 回復アイテム多め

第2章：適応期間
- 敵の種類増加
- 攻撃パターン複雑化
- リソース管理重要

第3章：挑戦期間
- 高速戦闘
- 複数ボス
- 戦術的判断必要

第4章：極限期間
- 最高難度
- リトライ前提
- 完璧なプレイ要求
```

## 1日のプレイセッション想定

### カジュアルプレイ（30分）
1. ログイン・デイリー報酬受取（2分）
2. サブミッション1-2個クリア（15分）
3. 装備強化・整理（5分）
4. 次回のミッション確認（3分）
5. セーブして終了（5分）

### 標準プレイ（1時間）
1. ストーリーミッション1個（20分）
2. サブミッション2-3個（20分）
3. 新エリア探索（10分）
4. ステーションでの準備（10分）

### ヘビープレイ（2時間以上）
1. ストーリー進行（40分）
2. レイドバトル挑戦（30分）
3. 全エリア探索（30分）
4. 装備最適化（20分）

## セーブ＆チェックポイント

### オートセーブ
- ミッションクリア時
- ステーション到着時
- 重要アイテム獲得時

### 手動セーブ
- ステーションでいつでも可能
- 複数スロット対応

### チェックポイント
- ボス戦前
- 長いミッション中の中間地点
- ストーリーイベント後

## エンディングへの道

### 通常ルート
```
各章のメインミッションクリア
    ↓
最終章解放
    ↓
最終ミッション
    ↓
ラスボス戦
    ↓
エンディング
```

### 完全クリアルート
```
全ミッションSランク
    ↓
隠しミッション出現
    ↓
真実の解明
    ↓
真ラスボス戦
    ↓
トゥルーエンディング
```

### スピードランルート
```
最低限のミッションのみ
    ↓
装備は最小限
    ↓
スキルと操作で突破
    ↓
タイムアタック記録
```
